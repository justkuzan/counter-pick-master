# Counter Pick Master

Лёгкое приложение WinForms для поиска контрпиков League of Legends по данным OP.GG. В статистику входят ранговые Solo/Duo от Железа до Золота включительно.

## Запуск

1. При необходимости установите [Microsoft .NET Desktop Runtime 10 x64](https://dotnet.microsoft.com/download/dotnet/10.0) для Windows.
2. Откройте `CounterPickMaster.exe` в Windows x64.
3. Для ярлыка на рабочем столе запустите `Create-Desktop-Shortcut.cmd`. Он создаст ярлык на EXE с иконкой OP.GG, встроенной в приложение.

При открытии поиск и роли становятся доступны после проверки синхронизации. Если OP.GG обновил статистику, окно показывает ход загрузки. При сетевой ошибке можно повторить проверку или вручную открыть сохранённый снимок. Локальный кэш хранится в `%LOCALAPPDATA%\CounterPickMaster\matchups.json`.

Выберите роль и начните вводить имя чемпиона на русском или английском. Щёлкните по подсказке или выделите её и нажмите Enter. При смене роли выбранный чемпион сохраняется. В списке показываются до восьми контрпиков. Чем выше винрейт контрпика против выбранного чемпиона, тем выше строка. При одинаковом проценте учитывается число игр.

## Источники

- [OP.GG MCP](https://github.com/opgginc/opgg-mcp) — матчапы, номер патча по тренду и список ролей. Приложение запрашивает `ranked` и `ibsg`. Используются прямые и доступные обратные матчапы из этого же диапазона и роли. Приоритет у прямой статистики. OP.GG возвращает ограниченный набор, поэтому для части чемпионов будет меньше восьми строк. В списке могут быть матчапы с небольшой выборкой, размер виден в колонке «Игры».
- [Riot Data Dragon](https://developer.riotgames.com/docs/lol#data-dragon) — русские и английские имена по общему ID.
- [Заметки Riot](https://www.leagueoflegends.com/en-us/news/tags/patch-notes/) — дата публикации патча, если соответствующая статья доступна. В противном случае в углу показано время записи статистики OP.GG.

В EXE встроен снимок патча 16.23, чтобы сохранённые данные можно было открыть даже при первом запуске без сети. При доступной сети приложение проверяет свежесть снимка при каждом запуске. На новом снимке OP.GG оно скачивает данные по пяти ролям до разблокировки поиска.

## Сборка

```powershell
dotnet publish CounterPickMaster.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=none
```
