# Проверка Counter Pick Master

| Проверка | Результат |
| --- | --- |
| Две полные загрузки через официальный OP.GG MCP | Патч 16.23, 173 чемпиона в справочнике, 254 сочетания чемпиона и роли |
| Покрытие обычных ролей | С контрпиками: топ 58, лес 62, мид 51, низ 36, поддержка 46 |
| Диапазон рангов | Во всех запросах матчапов использован `tier=ibsg` и `game_mode=ranked` |
| Перезапуск с кэшем | Проверка OP.GG и справочника Riot прошла, полный список матчапов повторно не скачивался |
| Потеря сети | Синхронизация завершилась ошибкой, сохранённый снимок открылся для локального поиска и смены ролей |
| Поиск по двум языкам | Проверены Иллаой, Трандл и Кай'Са по английским и русским запросам, в том числе с разным регистром и пунктуацией |
| Переключение ролей | Локальная выборка Топ → Лес → Топ для Трандла дала разные списки для ролей и вернула первый список при переключении обратно |
| Сортировка и отсечение | Проверены лимит 8 строк, порядок винрейтов, сортировка равных процентов по количеству игр, отсутствие дублей и исключение выбранного чемпиона |
| Дата и версия | Патч 16.23 по OP.GG, дата публикации заметок Riot 17.11.2026 |
| Сборка | Release, WinForms, Windows x64, один файл EXE |

Проверки загрузки, кэша, поиска и сортировки запускались на тех же классах, которые использует окно. Сборка выполнялась в Linux. Нажатия и отображение WinForms в Windows, повторный запуск именно EXE и фактическое создание ярлыка на рабочем столе Windows остаются непроверенными.
